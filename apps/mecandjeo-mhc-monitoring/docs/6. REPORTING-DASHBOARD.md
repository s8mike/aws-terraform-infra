# Reporting And Dashboard

Phases 5 and 7 implement manager visibility, historical reports, and CSV exports.

## Implemented Manager Views

- Live operator status.
- Active shift overview.
- Dashboard totals for active shifts, active tasks, active delays, completed tasks, containers, and delay minutes.
- Delay breakdown by standard delay type and optional custom delay type.
- Performance trends grouped by operator, crane, nature of work, or date.
- Date-filtered historical performance report with task-level operational context.
- CSV export with task duration, delay duration, effective work time, containers, moves per hour, and delay reasons.
- Export metadata history for traceability.

## Implemented Endpoints

- `GET /api/manager/dashboard`
- `GET /api/manager/operators/live-status`
- `GET /api/manager/shifts/active`
- `GET /api/manager/delays/breakdown`
- `GET /api/manager/performance/trends`
- `GET /api/reports/performance`
- `GET /api/reports/performance.csv`
- `GET /api/reports/exports`

## Security

- Manager dashboard routes require a valid bearer token.
- Only `manager` and `admin` users can access these views.
- Operator users are blocked from manager dashboard routes.
- Report routes do not modify operational work records.
- Managers see only their own export metadata; admins can inspect all export metadata.
